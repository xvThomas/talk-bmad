# Decision Log — prd-map-backend-2026-08-31

## 2026-08-31

**Decision: Remove `GET_GEOJSON_GEOMETRY` env var entirely rather than default to `true`.**
Context: Mary (BA) initially proposed defaulting to `true`. During requirements review, Xavierthomas confirmed the flag is conceptually wrong — if geometry is optional, use `distance_time`; if you call `route`, geometry is always needed.
Outcome: FR-1 / FR-2 — flag removed, not defaulted.

**Decision: Do not add `IntermediateLabels` to `RouteToolInput`.**
Context: Waypoints appear as discreet markers in Epic 8 (FR-MAP-06). No legend entry per waypoint is required. Labels would add complexity with no V1 consumer.
Outcome: Deferred. Noted in §5 Out of Scope.

**Decision: `DistanceTimeTool` is unaffected.**
Context: Labels are only meaningful alongside geometry. `distance_time` has no geometry and no legend requirement.
Outcome: FR-7 — `DistanceTimeToolInput/Output` not extended.
