# Decision Log — prd-map-frontend-2026-08-31

## 2026-08-31

**Decision: MapLibre GL JS over Leaflet.**
See `adr/adr-001-map-visualization-architecture.md` §Decision 2 for full rationale.
Outcome: FR-10.

**Decision: Decouple `MapProvider` from `ChatUIContext` via `ToolResultMapper` pattern.**
See `adr/adr-001-map-visualization-architecture.md` §Decision 1 for full rationale.
Outcome: FR-6 through FR-9, FR-24, FR-25.

**Decision: `MapPanel` is lazy-loaded.**
Context: MapLibre GL JS adds ≈ 220 KB gzip. The map panel is hidden at startup for all non-navigation sessions.
Outcome: NFR-1.

**Decision: Legend "Étapes" tab shows steps for selected itinerary only.**
Context: Showing steps for all itineraries simultaneously would be unreadably long. Scoped to the selected route on click.
Outcome: FR-20.

**Decision: Step clicks re-center the map but add no pin marker.**
Context: Xavierthomas confirmed this is acceptable for Epic 8. Adding pin markers per step would require a separate marker layer and is deferred.
Outcome: FR-22. Noted in §5 Out of Scope.

**Decision: `StartLabel`/`EndLabel` fallback to coordinate strings.**
Context: The LLM may not always provide labels (e.g., if coordinates were provided directly by the user without a prior geocode call).
Outcome: FR-18.

**Decision: Map panel state (open/closed, selected route) is NOT persisted across page reloads.**
Context: Xavierthomas confirmed itineraries reset with the session, not across page loads. Session = in-memory state.
Outcome: FR-9 (session reset clears state). No localStorage/sessionStorage requirement.
